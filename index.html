What is ZevOS?

⚡ x86_64

GRUB Multiboot2 boot and a transition into 64-bit long mode.

🧠 Kernel foundations

Physical memory management, a kernel heap, interrupts, PIT timing and keyboard input.

⚙ zinit

A service-manager foundation designed to become the system's PID 1 as userspace arrives.
